# Códigos de error

## E01 Sin producto
El código E01 indica que el bidón está vacío o el tubo de aspiración no está sumergido. Sustituya el bidón y pulse RESET durante 3 segundos.

## E04 Presión baja
El código E04 indica presión de agua inferior a 2 bar. Compruebe que la llave de entrada está abierta y limpie el filtro de entrada.

## E07 Caudal
El código E07 indica obstrucción en la línea de dosificación. Desmonte la boquilla y límpiela con agua tibia.
